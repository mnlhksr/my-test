# Learning Content

This directory is reserved for structured Croatian learning material.

The intended curriculum combines:
- the chapters, dialogues, grammar, vocabulary and exercises from *Kroatisch lernen? Nema problema!*, Band 1;
- high-frequency Croatian words and expressions;
- practical everyday situations and role-plays.

Book content should only be added when legitimately available to the system. Supplemental material should keep source/provenance and verification status where relevant.

For this write test, no textbook content has been copied into the repository.
